# **App Name**: Carmelinda Salon Manager

## Core Features:

- Appointment Scheduling: Manage appointments with a calendar view and booking options.
- Customer Management: Store customer details, appointment history, and service preferences.
- Service Catalog: Maintain a catalog of available services with descriptions and pricing.
- Inventory Tracking: Track inventory levels of products used in the salon.
- Automated WhatsApp Reminders: Send automated appointment reminders to customers via WhatsApp, managed as a tool with generative AI.
- Settings Management: Configure salon details, user permissions, and other settings.
- Service History: View each customer's history with their respective service dates and worker assignments

## Style Guidelines:

- Primary color: Soft lavender (#D1C4E9) for a calm, sophisticated atmosphere.
- Background color: Light gray (#F5F5F5), almost white, for a clean and modern look.
- Accent color: Pale rose (#F8BBD0) to complement the lavender and add a touch of elegance.
- Headline font: 'Playfair', serif, for an elegant, high-end feel; body font: 'PT Sans' sans-serif.
- Use minimalist icons related to salon services and tools.
- Maintain a clean and spacious layout with clear sections for each function.
- Subtle transitions and animations for a polished user experience.
